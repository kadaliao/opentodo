# 架构

## 客户端（`app/`）

本地优先：所有读写都先落到本机 SQLite，界面直接订阅数据库的变化；联网时再由同步引擎和服务器交换改动。没网、服务器挂了，应用照样能用。

| 层 | 位置 | 说明 |
|---|---|---|
| 数据 | `lib/data/db.dart` | drift 表定义：清单 `TaskLists`、任务 `Tasks`、子任务 `ChecklistItems` |
| 仓库 | `lib/data/repo.dart` | 所有写操作的唯一入口，负责打同步标记 |
| 领域 | `lib/domain/` | 纯函数，单测覆盖：日期标签、快速添加解析、视图分组 |
| 状态 | `lib/state/providers.dart` | Riverpod：数据库流、当前视图、选中任务、每分钟刷新的时钟 |
| 界面 | `lib/ui/` | 宽屏三栏（≥1000）、中屏两栏（≥640，详情另开一页）、手机单栏加抽屉 |

### 数据约定

- **ID** 用 UUID v7（按时间有序），客户端离线生成，不依赖服务器。
- **每张表都有同步字段**：`createdAt`、`updatedAt`（毫秒）、`deletedAt`（删除标记，非空即已删除，行本身保留到服务器确认）、`serverVersion`（服务器给的版本号，0 表示从未同步）、`dirty`（本地有未推送的改动）。仓库的每次写入都会更新 `updatedAt` 并置 `dirty`。
- **日期是“浮动”的日历日期**：`dueDate` 存 `YYYY-MM-DD` 字符串，`dueTime` 存当天第几分钟（为空表示全天）。出差换时区时，18 号的任务仍在 18 号。`timeZone` 字段先留着，给以后“固定时刻”的提醒用。
- **收集箱**不是一行数据，而是固定的 `listId = 'inbox'`。
- **垃圾桶和删除是两回事**：`trashedAt` 是放进垃圾桶，可以恢复；`deletedAt` 是永久删除，留作同步的删除标记。
- **标签**以 JSON 数组存在任务行里（`["工作","出行"]`），同步时跟着任务走，不需要单独的关联表。

### 快速添加

`lib/domain/quick_add_parser.dart` 把一行输入拆成标题、日期、时间、标签、优先级，并返回每段识别文字的位置，供输入框高亮。支持：今天/明天/后天/大后天、今晚/明早、周X/下周X/这周X/下下周X、周末、N天后/N周后、X月X日、X号、M/D、YYYY年M月D日；上午/下午/晚上/中午/凌晨 + X点/X点半/X点一刻/X:XX、3pm；`#标签`、`!高 !中 !低`。没写上下午时，1–6 点按下午算。一周从周一开始。

## 同步（M2）

服务端在 `server/`：Go，SQLite（纯 Go 驱动，不用 cgo），部署时只有一个程序文件加一个数据库文件。存储层封装在 `internal/store`，用户量上来后换 PostgreSQL 只改这一层。

| 接口 | 说明 |
|---|---|
| `POST /v1/auth/register`、`/v1/auth/login` | 邮箱 + 密码（bcrypt），返回不透明的会话令牌，服务器只存它的 SHA-256 |
| `POST /v1/auth/logout`、`GET /v1/me` | 需要 `Authorization: Bearer <令牌>` |
| `POST /v1/sync` | 推拉合一：请求带 `cursor` 和本地改动，响应带被接受的改动、新改动、新 `cursor` 和 `hasMore` |

- 每个用户有自己的递增版本号。服务器每存一条改动就给它一个新版本号；客户端记住看到的最大版本号（`cursor`），下次只拉更新的。一页最多 500 条，`hasMore` 为真就接着拉。
- 冲突按整行“`updatedAt` 新者胜”。推上来的改动比服务器上的旧时，服务器不存，并把服务器上的版本发回去，客户端用它覆盖本地。
- 客户端先应用拉回的记录、再把推送成功的行标记为已同步：服务器在存这次推送之前就读好了要发回的记录，所以发回的可能比刚推上去的旧；这时本地行还是脏的，会被保留（集成测试“the newer edit wins a conflict”覆盖这个情况）。
- 推送期间本地又改过的行，`updatedAt` 已经变了，不会被误标为已同步，下次再推。
- 删除靠 `deletedAt` 删除标记传播；服务器确认后，客户端把已同步的删除标记物理删掉。
- 已知限制：用设备时钟比较新旧，设备时间不准时可能误判；以后改成混合逻辑时钟（HLC）。

客户端在 `app/lib/sync/`：`codec.dart`（逐字段的网络格式，旧客户端能读新字段）、`sync_engine.dart`（一次同步）、`account.dart`（登录接口和错误文案）；调度在 `app/lib/state/sync_providers.dart`。账号、令牌和同步进度存在本地的 `KeyValues` 表里，不参与同步。
