# 路线图

参照对象是滴答清单（本机截图在 `reference/`），但名字、图标、插画、文案和配色都用自己的。

## M1 本地核心（已完成）

- [x] 数据层：清单、任务、子任务，带同步字段
- [x] 智能清单：今天（含已过期）、明天、最近 7 天（按天分组）、收集箱、已完成（按完成日分组）、垃圾桶
- [x] 自建清单（emoji 图标）、标签视图（按清单分组）
- [x] 快速添加：中文自然语言识别日期时间、`#标签`、`!优先级`，输入时高亮
- [x] 任务详情：标题、备注、日期时间、优先级、子任务、移动清单、删除/恢复/永久删除
- [x] 右键/长按菜单：改日期、优先级、移动、删除
- [x] 自适应布局：电脑三栏、中屏两栏、手机抽屉 + 详情页
- [x] macOS 实机运行，iOS 模拟器编译

## M2 同步与账号

- [x] Go 服务：邮箱注册登录、会话令牌、按用户递增版本号的变更日志、推拉合一的同步接口（SQLite）
- [x] 客户端同步引擎：本地改动 2 秒后自动同步、每分钟一次、回到前台时一次；新者胜的冲突处理；删除标记传播
- [x] 登录界面和同步状态；未登录时纯本地可用，登录后合并本地数据，没动过的欢迎任务会被丢掉
- [x] 部署上线：`https://todo.liaoxingyi.com`，Caddy 自动 HTTPS，systemd 加固，每日备份
- [x] 登录接口限流（每 IP 每分钟 10 次）
- [ ] 忘记密码、手机号 / Apple / 微信登录
- [ ] 令牌改存系统钥匙串（现在存在本地数据库里）
