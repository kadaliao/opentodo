# 路线图

参照对象是滴答清单（本机截图在 `reference/`），但名字、图标、插画、文案和配色都用自己的。

没注明的条目两个客户端都有；注明“Swift 版”的只在苹果平台的 Swift 客户端（`apple/`）里，Flutter 客户端（`app/`）没有。

## M1 本地核心（已完成）

- [x] 数据层：清单、任务、子任务，带同步字段
- [x] 智能清单：今天（含已过期）、明天、最近 7 天（按天分组）、收集箱、已完成（按完成日分组）、垃圾桶
- [x] 自建清单（emoji 图标）、标签视图（按清单分组）
- [x] 快速添加：中文自然语言识别日期时间、`#标签`、`!优先级`，输入时高亮
- [x] 任务详情：标题、备注、日期时间、优先级、子任务、移动清单、删除/恢复/永久删除
- [x] 右键/长按菜单：改日期、优先级、移动、删除
- [x] 自适应布局：电脑三栏、中屏两栏、手机抽屉 + 详情页
- [x] macOS 实机运行，iOS 模拟器编译

## M2 同步与账号

- [x] Go 服务：邮箱注册登录、会话令牌、按用户递增版本号的变更日志、推拉合一的同步接口（SQLite）
- [x] 客户端同步引擎：本地改动 2 秒后自动同步、每分钟一次、回到前台时一次；新者胜的冲突处理；删除标记传播
- [x] 登录界面和同步状态；未登录时纯本地可用，登录后合并本地数据，没动过的欢迎任务会被丢掉
- [x] 部署上线：`https://todo.liaoxingyi.com`，Caddy 自动 HTTPS，systemd 加固，每日备份
- [x] 登录接口限流（每 IP 每分钟 10 次）
- [ ] 忘记密码、手机号 / Apple / 微信登录
- [x] 令牌改存系统钥匙串（Swift 版；Flutter 版还存在本地数据库里）

## M3 视图

- [x] 日历：月、周、3 天、日、日程；拖动改日期和时间（拖进“全天”去掉时间），点空白格子新建；重复任务展开以后的日期；按清单筛选、显示已完成、键盘切换（D 3 W M A、T、← →）
- [x] 日历：农历日、传统节日、法定节假日的休 / 班标注（可关）
- [x] 日历：年视图、多周；“安排任务”面板（把没日期的任务拖进日历）（Swift 版）
- [x] 清单的看板视图（分组 = 列；每个清单在本机选列表或看板）
- [x] 时间线视图（清单里和列表、看板并列；日 / 周 / 月缩放；分组是泳道；拖动改日期和分组、拖右边缘改结束日期、点空白新建；无日期一栏拖进拖出）
- [x] 时间线补充：拖左边缘改开始日期、手机上长按两头改日期；今天 / 明天 / 最近7天、标签、过滤器也能用时间线（泳道按清单 / 标签 / 优先级）
- [x] 手动排序（拖动，电脑直接拖、手机长按拖）、自定义分组（列表里是标题、看板里是列，可同步）
- [x] 置顶、排序方式（自定义 / 时间 / 优先级）、在今天 / 明天 / 最近7天里拖到别的日子改期
- [x] 多选批量操作（改日期、优先级、清单、标签，完成、置顶、复制、删除；可撤销）
- [x] 按标题排序（拼音，中英文一起）、多选后一起拖、拖动分组（列表里拖标题、看板里拖列）
- [x] 日历里多选（⌘ / Shift 点选、⌘A、手机从菜单进），批量面板，选中的一起拖（同样挪几天；拖到小时格上按同样的分钟挪）
- [x] 最近7天里没有任务的日子也显示，可以往里拖；搜索可以用拼音和首字母
- [x] 分组方式（自定义分组 / 时间 / 清单 / 标签 / 优先级 / 不分组，每个视图各自选）、按标签排序；拖进一组就改成那组的日期、优先级、清单或标签
- [x] 搜索（任务标题、描述、子任务、标签，清单、标签、过滤器名；关键词标黄；⌘F）、过滤器（按清单、标签、日期、优先级、内容，普通 / 高级两种编辑，可同步）

## M4 提醒与重复

- [x] 本地通知提醒（准时、提前 N 分钟/小时/天、全天任务当天或提前几天的某个时刻、自定义），可设多个；iOS/macOS 申请通知权限，被拒时提示去系统设置
- [x] 点通知打开对应任务（应用开着或被通知唤起都行）
- [x] 重复任务（RRULE：每天/每周几/每月几号或第几个周几/每年/工作日/自定义间隔，按到期日期或完成日期，截止日期或次数结束），完成后移到下一次并留一份已完成记录，可撤销；跳过此次
- [x] 快速添加识别“每天”“每周一三五”“每月15号”“每个工作日”“每年3月8日”等
- [x] 通知上的“完成”“稍后提醒”按钮（iOS / Android 在后台处理，macOS 交给应用；稍后提醒的时长在设置里）
- [x] 法定工作日重复（跳过法定节假日、调休上班照常，数据随应用发布，每年加一年）、农历每年 / 每月重复，快速添加也能识别
- [x] 艾宾浩斯记忆法（Swift 版）
- [x] 设置页：系统通知状态；任务默认值（有时间 / 全天任务的默认提醒、时间段默认时长），存在本机
- [ ] Android 上实机验证通知（配置已按插件文档写好，还没编译过）
- [x] 时间段任务（开始–结束）：日期对话框的“时间段”、快速添加“下午3点到5点”、日历按时长画、拖下边缘改结束、跨天的在每一天显示
